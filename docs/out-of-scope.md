# Out of scope

Explicitly excluded unless the owner changes it (AGENTS.md §1, owner answers 2026-10-11).
A feature request touching any of these needs an owner decision first.

| Item | Note |
|---|---|
| PDF / print export | Never trade practical behaviour for exportability. Original PDFs are kept byte-identical. |
| Sync, cloud, accounts | No network at runtime. |
| Collaboration / sharing | — |
| Mobile, web, tablets-as-devices | Desktop only. |
| Non-Linux and non-Wayland platforms (X11, Windows, macOS) | May happen to work; costs no design effort. |
| Microsoft OneNote (or other) format compatibility | — |
| Look-alike of any existing product | No copied UI or assets. |
| Local-file links | Owner chose note/folder, canvas-position and web links only. |
| Touch input (finger drawing/gestures on touchscreens) | v1 [proposal]; touchpad gestures for pan/zoom are in scope. |
| Learned (stage-2) prettify re-synthesis | Research survey only in Phase 2; no commitment. |
| Languages other than German and English | Architecture allows packs; none shipped. |
