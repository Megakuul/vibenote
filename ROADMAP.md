# vibenote roadmap

A fast, paper-like handwriting workspace for Linux/Wayland. Spec: `SPEC.md`. Plan:
`plan/execution-plan.md`. Live requirement status: `docs/parity.md` (generated by
`cargo xtask parity`).

**Honest status (2026-10-13):** bootstrap complete (Gate D passed 2026-10-13); M1 implemented and
reviewed; M2 done and reviewed (storage thread, persistent undo, lazy open, settings, recovery after a failing disk). A first GUI app exists: a Wayland window that
inks with the pen (no toolbar or other UI yet). The headless engine, storage (now on its own
thread), pen-input state machine, headless renderer and the full test harness exist.
**29 / 71** requirements pass their acceptance tests.
